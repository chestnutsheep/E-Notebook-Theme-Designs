## 〇、为什么上一版有的胶带会翻车（先讲清，以后你自己能避）

异形胶带 = 一条"**有贴边 + 有景观轮廓边**"的装饰带。三条铁律：

1. **必须有一条平直贴边**：胶带是"贴"的，至少一边要平（贴纸面那侧），另一边才做景观轮廓。两边都波浪 / 都模糊 → 不像胶带，像破布。
2. **轮廓要有"可识别的连续边界"，避开两种死刑形状**：
   - **无形体**（烟岚 / 云雾 / 水汽）：没有边界，AI 只能吐一团模糊雾块，模切不了也好看不了。
   - **chaotic 跳动形**（跃动火苗）：边缘刺乱、无重复节奏，die-cut 出来乱糟糟。
   → 一律改成"有剪影边界 + 有节奏重复"的轮廓：远山、城堞、飞檐、林线、滴落。
3. **带面纹样要"可平铺重复"**：胶带要能拉长，所以内部母题是连续重复的小景（星点、山重、波纹、藤节），不是一张一次性大图。

> **已下架的上一版设计**：E-06 烟岚胶带（无形体）、E-07 火焰胶带（chaotic 跳动）。
> **替换为**：T-02 远山层叠、T-03 宫墙城堞、T-07 飞檐云楼、T-09 烛泪垂落——四类有明确边界、有重复节奏的轮廓。

## 二、异形胶带提示词库（全中文，可直接用）

**每条固定骨架**：
`一段异形和纸/PET胶带 + 下缘平直贴边 + 上缘[景观]轮廓 + 带面[可重复纹样] + 材质(和纸肌理/PET微反光/撕边模切) + [本卷DNA] + 四周完全透明、异形模切、非方正 + 高清`

### T-01 银河胶带 —— 卷一《天上谣》
一段异形和纸胶带，下缘为平直贴边，上缘呈银河蜿蜒起伏的轮廓；带面是银白流光河，河中漂着桂金与银白星点疏密散布、可连续重复；和纸肌理细微，PET 面微反光；四周完全透明，异形模切，非方正。唐宋水墨工笔融合，银白月华底、桂金破色、瑶草青霞粉，仙绮半透发光。高清。

### T-02 远山层叠胶带 —— 卷二 / 卷一一（替换原"烟岚"）
一段异形和纸胶带，下缘平直贴边，上缘是层叠远山剪影轮廓（近山实、远山淡，两三重连续起伏）；带面填墨青，山坳间缀磷火幽绿与星银微光，可连续重复；和纸肌理，撕边模切；四周透明。唐宋水墨工笔融合，墨青夜底、磷火幽绿破色、冷红泣露，幽冷凄艳。高清。

### T-03 宫墙城堞胶带 —— 卷九 / 卷五（新增）
一段异形和纸胶带，下缘平直贴边，上缘为古代城堞垛口剪影轮廓（连续齿状起伏）；带面填燕脂夜紫，垛口透出甲光金边光，可连续重复；和纸肌理，撕边模切；四周透明。唐宋水墨工笔融合，燕脂夜紫底、甲光金破色、霜白旗红，烈色绚烂。高清。

## 三、两条工作流（中文）

- **工作流① 直接异形片**：上面 T-01～T-10 都是"一段异形片"，生成后四周透明，直接当一段点缀胶带用，可旋转、错落粘贴。
- **工作流② 平铺长条 + 后期模切**：若要做超长连续胶带，把提示词里"一段异形和纸胶带"改成"一条可平铺长胶带，[上缘轮廓]连续重复，无缝 tileable"，生成方正长条后，在 PS / Procreate 用钢笔按上缘轮廓建立蒙版、反选删除，即得异形长胶带（边缘比 AI 直接出的更干净）。

---

## 四、透明与模切（呼应总纲）

1. **生图**：豆包 / 即梦勾选"透明背景"；提示词已写"四周完全透明、异形模切"。
2. **去底**：rembg / PS 移除背景。带面里的磷火、碧火、流光等**半透细节在通道手动修补，勿误删光晕**。
3. **修边**：1–2px 去边（Defringe）+ 轻羽化；半透光晕保留，勿硬切。
4. **异形长胶带裁切**：见工作流②。

## 五、混搭建议

- 异形胶带是"景观入侵页面"的惊喜元素——**一条即可**，别满页都是，否则失去"异形"的惊艳感。
- 暗卷（二/三）的远山、江岸、水波胶带，配亮卷（一/五）的银河、枝条胶带，冷暖交替最出彩。
- 同一条胶带可**横贴 / 斜贴 / 折角贴**，轮廓朝不同方向，手账立刻有"手作感"。
